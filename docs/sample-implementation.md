# Public-source code in libGLcore

Much of `libGLcore.so` is not board code. The software renderer, the display-list machinery, the pixel paths and the name tables descend from the OpenGL sample implementation that SGI published, which this repository carries as the `ogl-sample` submodule. This chapter gives each such routine of the 6.5.30m N32 library its own entry: what it does, the public source file that holds the same routine, and whether it reaches the board. None of the routines below stores to a board window; the board-specific routines are in [libglcore-functions.md](libglcore-functions.md) and [opengl.md](opengl.md).

Public source: the sample implementation under `ogl-sample/gfx/lib/opengl`. Paths in the entries are relative to `ogl-sample`. The shipped source file of a routine is the heading it sits under, for example `so_names.c`; the sample file that holds the same routine is named in the entry.

Labels follow [AGENTS.md](../AGENTS.md). An entry is **Established** only where the whole routine was read against the public body. **Inferred** entries are matched to the public routine by its name, its direct calls and its size, and were not read end to end. Where an entry says it differs from the public body, the difference was read in the disassembly. Entries describe the N32 library of the 6.5.30 media (`builds/6.5.30-media/usr/gfx/arch/IP30ODSY32`), which the installed copies and the IP35 copies repeat byte for byte; the patch builds, the O32 and 64-bit builds hold different code and are not credited by them.

Direct calls that the disassembly labels with the name of a neighbouring symbol are calls to file-local routines.
