Support Information > Odydiags Quick Reference Guide > Odydiags
 
    
  1. Log in as root, and set the console to the terminal that is connected to the first serial port by using one of the following commands:

    # chkconfig console d
        or
    # nvram console d

  2. Disable the window system using the following command:

    # chkconfig windowsystem off

  3. Reboot the system.
  4. Change your working directory to /usr/diags/ody.
  5. To run all standard tests, execute the following commands:

    # ./run.pl -all
    # ./run.pl 1 -rts
    # ./run.pl 1 -ifio

    Note: Check the following files after executing each command to see test details and results:

    summary.log
    loopsummary.log
    details.log

  6. Get a list of available tests using the following command:

    # ./odydiags -help
    Select 5 from the list of options.

  7. To run specific tests ,use the following command:

    # odydiags -<testname> -<options>

  8. Read the Vpro Odyssey Graphics Diagnostic Reference for a detailed description of the tests and the available option parameters.
